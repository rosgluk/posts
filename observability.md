## Monitoring

- [DORA Metrics Guide: Measuring DevOps Success](https://www.glukhov.org/observability/devops-metrics-dora/) — Comprehensive guide to DORA metrics: deployment frequency, lead time, change failure rate, and time to restore. Learn how to measure and improve DevOps performance.
- [GPU monitoring applications in Linux / Ubuntu](https://www.glukhov.org/observability/gpu-monitoring-apps-linux/) — NVIDIA GPU monitoring applications in Linux / Ubuntu - list and comparison
- [Install and Use Grafana on Ubuntu: Complete Guide](https://www.glukhov.org/observability/grafana-installing-using-in-ubuntu/) — Step-by-step guide to installing, configuring, and using Grafana on Ubuntu for powerful monitoring, visualization, and observability with multiple data sources
- [Modern Alerting Systems Design for Observability Teams](https://www.glukhov.org/observability/alerting/) — A practical pillar page on alerting design, routing, noise reduction, and human response across observability systems, paging tools, and chat platforms.
- [Monitor LLM Inference in Production (2026): Prometheus & Grafana for vLLM, TGI, llama.cpp](https://www.glukhov.org/observability/monitoring-llm-inference-prometheus-grafana/) — Learn how to monitor LLM inference in production using Prometheus and Grafana. Track p95 latency, tokens/sec, queue duration, and KV cache usage across vLLM, TGI, and llama.cpp.
- [Observability for LLM Systems: Metrics, Traces, Logs, and Testing in Production](https://www.glukhov.org/observability/observability-for-llm-systems/) — A deep guide to observability for LLM systems: metrics, distributed tracing, logs, profiling, synthetic testing, and SLOs.
- [Prometheus Monitoring: Setup & Best Practices](https://www.glukhov.org/observability/monitoring-with-prometheus/) — Guide to Prometheus monitoring system: installation, configuration, PromQL queries, exporters, alerting, and integration with Grafana for comprehensive infrastructure observability.
